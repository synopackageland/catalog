# Syno Package Land catalog

`catalog.yaml` is the single list of packages shown on www.varvis.me and served to DSM Package Center by packages.varvis.me.
Edit it and commit to `main`; the package source and website pick up the change within minutes, with no redeploy.
SPK files stay in each package repository's GitHub Releases; packages.varvis.me streams them, nothing is stored in R2.
