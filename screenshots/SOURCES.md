# Upstream screenshot sources

Official upstream Web UI examples, retrieved 2026-11-06. Sources below are pinned
to immutable upstream commits. These illustrate upstream interfaces, not a capture
of a particular DSM package version. Existing package screenshots are unchanged.

All images retain their original pixel dimensions. Source PNG/JPG files below 500 KB
are verbatim copies; larger PNGs and WebP sources are encoded as JPEG to meet this
repository's 500 KB and PNG/JPG hosting rules. There is no cropping or retouching.
Jellyfin images have format/compression changes only (CC BY-ND 4.0 section 2(a)(4)).

Upstream license texts and notices are included in [licenses/](licenses/).
The licenses listed apply to the upstream screenshot files; depicted third-party
media artwork and trademarks remain with their respective owners.

candidates were fragments or alternate-language views rather than additional

No images were added for Vaultwarden (no suitable official Web UI screenshot
found) or Home Assistant (the frontend repo candidates are legacy mobile views
or a montage with personal/location data; website images use CC BY-NC-SA 4.0).
OpenList already has two package screenshots; its core/frontend repos have no
suitable screenshots, and the docs repo has no redistribution license. Download
Hub already fills all five gallery slots with screenshots of the packaged UI.
